<h1>Overview</h1>
Welcome to our project! This was made by Elijah Ingerson, Michael Mille, and Andrew Dailey for our Secure Software Engineering course at Florida Polytechnic University.
This game is intended to teach people how to recognize spam emails by allowing them to try to reach a highscore and get onto the leaderboard.

<h1>How to Use</h1>
<h3>Windows</h3>
Go to the latest release and download Windows.zip. Extract the zip file, then run the executable in the folder and the game should start!

<h3>Linux</h3>
Similar to Windows, go to the latest release and download Linux.tar.gz. Extract the file and run the executable in the folder and the game should start!

<h3>HTML</h3>
Unfortunately, while there is an HTML build, it does not currently function. Please use either the Windows or Linux build.
